# Smart Calendar Booking Assistant (Telegram)

## 📌 Project Description

An AI-powered Telegram Calendar Booking Assistant built using n8n.

The assistant allows users to interact through Telegram and perform calendar-related tasks using an AI Agent.

## 🚀 Features

- Telegram-based interaction
- AI-powered calendar assistant
- Check calendar availability
- Create events
- Update events
- Delete events
- Simple conversational interaction

## 🛠️ Technologies Used

- n8n
- Telegram
- AI Agent
- Google Calendar
- OpenAI Chat Model

## 🔄 Workflow

Telegram Trigger
        ↓
AI Agent
        ↓
Calendar Tools
        ↓
Google Calendar
        ↓
Telegram Response

## 📂 Project File

The n8n workflow is provided as a JSON file in this repository.

## ⚙️ How to Use

1. Install or open n8n.
2. Download the workflow JSON file from this repository.
3. Import the workflow into n8n.
4. Configure your Telegram credentials.
5. Configure your Google Calendar credentials.
6. Configure your AI model credentials.
7. Activate the workflow.
8. Start interacting with the assistant through Telegram.
